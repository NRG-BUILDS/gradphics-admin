# Gradgram Admin

Standalone React and Vite workspace for Gradgram administration.

## Start locally

```sh
npm install
npm run dev
```

Set `VITE_API_URL` to the API version root, for example `http://localhost:4000/api/v1`. The workspace requires a verified administrator account provisioned with `npm run admin:bootstrap` from `server/`.

Admin access uses the server's JWT sign-in/refresh endpoints. Access tokens stay in Redux memory; the rotating refresh token is held in session-scoped browser storage to recover after a same-tab reload. Requests refresh once after an expired access token and sign out when refresh fails. All dashboard, user, support, and template data comes from protected API routes; no demo records are used as fallback data.

## Available views

- Overview of users, revenue, designs, and support activity
- Searchable/paginated customer list, account details, payment history, and session-revoking suspension
- Paginated support inbox with email replies, delivery failures/retry, resolve, and reopen
- Template library with form or JSON authoring, versioned prompts, image uploads, publication controls, and archive

Create templates with the form editor or switch to the JSON editor. For existing templates, edit the `metadata` and `version` objects; every save appends an immutable version. Upload the template preview through the authenticated admin asset API; the confirmed preview asset is attached to the template and automatically passed to the image model as its layout reference. `version.imageInputs` defines customer-submitted subject photos only. Template slugs are generated by the server from the template name.
